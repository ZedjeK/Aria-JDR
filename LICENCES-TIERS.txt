Aria JDR : composants tiers embarqués
=====================================

Ce fichier liste tout ce que l'exe embarque et qui n'a pas été écrit pour
Aria JDR. Il est mis à jour à chaque version et joint au zip.

Pour chaque composant : nom, version, source officielle, licence, et la façon
dont il a été vérifié.

Interpréteur Python et ses bibliothèques natives
------------------------------------------------

Python (interpréteur, bibliothèque standard)
  Version      : 3.11 (la version exacte de chaque zip est dans BUILDINFO.txt)
  Source       : https://www.python.org
  Licence      : Python Software Foundation License (PSF-2.0)
  Vérification : installé par actions/setup-python, épinglée par SHA dans
                 les workflows. L'empreinte de l'interpréteur n'est pas
                 contrôlée par ce dépôt.

Bibliothèques natives livrées avec Python 3.11 et copiées dans l'exe :
OpenSSL (libssl, libcrypto), libffi, bzip2, liblzma, runtime Visual C++
(VCRUNTIME140).
  Version      : celle qui accompagne l'interpréteur ci-dessus
  Source       : https://www.python.org, https://openssl-library.org,
                 https://sourceware.org/libffi, https://sourceware.org/bzip2,
                 https://tukaani.org/xz
  Licence      : OpenSSL 3 : Apache-2.0 ; libffi : MIT ; bzip2 : licence BSD
                 de bzip2 ; liblzma : domaine public ; VCRUNTIME140 :
                 redistribuable Microsoft Visual C++
  Vérification : voir Python ci-dessus. Les versions exactes ne sont pas
                 relevées par ce dépôt.

Interface web locale
---------------------

FastAPI, uvicorn et leurs dépendances, copiés dans l'exe avec les modules Python qu'ils fournissent :
  FastAPI 0.129 (MIT), Starlette 0.52 (BSD-3-Clause), uvicorn 0.41 (BSD-3-Clause), pydantic 2.12 et pydantic-core 2.41 (MIT),
  annotated-types (MIT), annotated-doc (MIT), typing-extensions (PSF-2.0), typing-inspection (MIT), anyio (MIT),
  idna (BSD-3-Clause), h11 (MIT), click (BSD-3-Clause), colorama (BSD-3-Clause)
  Version      : celle installée à la construction ; FastAPI et uvicorn sont dans BUILDINFO.txt, les autres ne sont pas
                 relevées. Les numéros ci-dessus sont ceux du poste de l'auteur au 2026-11-15.
  Source       : PyPI, page de chaque projet
  Licence      : celle indiquée à côté de chacun, lue dans les métadonnées des paquets installés
  Vérification : exigences dans requirements.txt, installées par pip. Aucune empreinte n'est verrouillée.

Polices
-------

Space Grotesk (500, 600, 700) et IBM Plex Mono (400, 500, 600), alphabet latin
  Version      : fichiers .woff2 au format Fontsource, copiés d'Aria Pilote ; la version n'est pas relevée
  Source       : https://github.com/floriankarsten/space-grotesk et https://github.com/IBM/plex
  Licence      : SIL Open Font License 1.1 (les textes sont dans appli/statique/polices)
  Vérification : aucune empreinte publiée n'a été comparée
