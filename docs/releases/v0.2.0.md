**Aria JDR** 0.2.0 : le combat à pied est mené par le code, le MJ le raconte.

Un exe portable pour Windows, joint à cette release. Il ouvre le jeu dans ton navigateur.

## Nouveautés

- **Le code mène le combat à pied** : à chaque tour, une petite IA joue les ennemis (un bretteur fonce, un tireur s'abrite et vise ; chacun tient compte de son moral, de son arme, du couvert et du nombre d'attaquants déjà sur sa cible). Le MJ ne tire plus leurs dés : les allers-retours de 25 à 40 secondes à chaque action du MJ disparaissent du combat à pied (gain de durée mesuré en banc seulement, pas sur une longue partie).
- **Un menu pour ton tour** : attaquer, viser, recharger, débloquer, changer d'arme, te mettre à couvert, lancer un sort à une cible, stabiliser un blessé, parler, tenter autre chose, fuir, terminer le tour. Dans la page, des boutons (clic ou touches 1 à 9) ; les options impossibles sont grisées, avec la raison.
- **Le MJ raconte** chaque round à partir des faits du code, sans chiffre et sans rien décider à ta place. « Parler », « Autre action » et « Fuir » lui rendent la main pour cette action ; à la fin du combat, il écrit les moments forts, et le code le fait à sa place s'il se tait.
- **Réglages de combat** : quand le MJ raconte (à chaque round, à la fin, jamais), les PV exacts des ennemis, le choix de ta défense à chaque attaque, et un essai éteint par défaut : les ennemis choisis par le MJ plutôt que par l'IA du code (le code garde toujours son IA en repli).
- **Les combats avec un drone, une arme de zone, un lanceur de sorts ou un véhicule** restent menés par le MJ, comme dans la 0.1.0.
- **Banc d'essai** : 83 situations dont 23 pièges, avec dix situations propres au combat à pied (récits, « Parler », « Autre action », fuite). Un simulateur de combats et un mini-banc du plan accompagnent le jeu pour les contrôles.

## À savoir

- **Le serveur llama et les modèles ne sont pas dans l'exe** : ils pèsent plusieurs Go. L'exe cherche le dossier `Aria-LLM` (avec `llama-prism` et `modeles`) à côté de lui, puis dans le dossier de l'utilisateur. Le README explique où les trouver.
- **Matériel testé** : une seule carte, une NVIDIA RTX 4080 SUPER (16 Gio). Aucun autre matériel n'a été essayé. Le serveur du MJ occupe environ 13 Gio de VRAM : ferme ce qui utilise la carte, par exemple le moteur d'Aria Studio.
- **Modèle qualifié** : Qwen3.8 27B (quantification Q3_K_XL), contexte de 16 384 jetons. Gemma 4 26B charge et tourne, mais n'a pas passé le banc.
- **Mesures de cette version** : au banc, 54 situations normales sur 60 et les 23 pièges ont réussi, avec 128 jetons de réflexion. Les échecs sont des ratés isolés (une seule des deux répétitions), sans lien avec le combat. Le banc a une part de hasard : une situation peut réussir une fois et échouer la suivante.
- **Le combat mené par le code est jeune** : l'IA des ennemis est réglée par un simulateur (deux voyous contre un débutant : environ deux victoires sur trois, en trois rounds et demi) et le récit du MJ est vérifié par le banc. Les ennemis choisis par le MJ restent un essai éteint par défaut : le mini-banc du plan est concluant (100 % de plans valides, 7 secondes en médiane, caractères respectés), mais le jugement sur des combats joués reste à faire.
- **Au premier lancement, qualifie le MJ** dans les Réglages : environ trois quarts d'heure à une heure, avec le serveur du MJ qui occupe la carte graphique. On peut interrompre sans perdre le profil actuel. Après cette mise à jour, requalifie-le : le prompt du MJ a changé.
- **Créer une campagne prend plusieurs minutes** : le MJ génère l'univers (six minutes à l'essai). La page affiche depuis combien de temps le jeu travaille.
- **Une seule partie à la fois**, et fermer l'onglet n'arrête pas la partie : elle continue côté serveur, et la page la reprend quand on la rouvre.
- **Aucune connexion vers Internet** : l'interface est servie par ton PC seulement (`127.0.0.1:8420`), le serveur du MJ écoute sur `127.0.0.1:8080`. Un jeton tiré à chaque lancement garde l'interface.
- **Pas d'installation, pas de mise à jour automatique** : on remplace l'exe à la main. La console (`python -m aria`, depuis les sources) reste là en cas de souci.
- Certains antivirus signalent à tort les exe PyInstaller : c'est un faux positif connu.

## Installation

1. Télécharge `Aria-JDR-0.2.0.zip` ci-dessous.
2. Décompresse d'abord le zip en entier (clic droit, « Extraire tout »). Choisis un dossier stable (pas Téléchargements). Lancé depuis l'aperçu du zip dans l'Explorateur, l'exe démarre sans les fichiers livrés à côté de lui.
3. Lance `Aria-JDR.exe` : l'interface s'ouvre dans ton navigateur par défaut.
4. L'exe n'est pas signé : si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires », puis sur « Exécuter quand même ».

## Mise à jour depuis une version précédente

Il n'y a pas de mise à jour automatique. Ferme le jeu (bouton « Quitter » de l'interface), décompresse le nouveau zip en entier, puis remplace l'exe par le nouveau (ou lance-le depuis un dossier à côté de l'ancienne version, que tu peux garder le temps de vérifier).

Tes parties sont dans `%USERPROFILE%\.Aria-JDR` et sont reprises telles quelles.

## Comment vérifier ce que tu as téléchargé

L'empreinte du zip est dans `Aria-JDR-0.2.0.zip.sha256`. Dans PowerShell :

```powershell
(Get-FileHash .\Aria-JDR-0.2.0.zip -Algorithm SHA256).Hash
```

L'empreinte seule ne prouve pas d'où vient le fichier. Pour vérifier qu'il a bien été construit par ce dépôt :

```powershell
gh attestation verify .\Aria-JDR-0.2.0.zip --repo ZedjeK/Aria-JDR
```
